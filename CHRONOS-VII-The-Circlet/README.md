# CHRONOS-VII — The Circlet

**Lexi.PHYS · EXPERIMENTAL / CINEMATIC SIMULATION ONLY**

A safe software conversion of the CHRONOS-VII archive into:

1. An interactive **spacetime sandbox** (first safe demo)
2. Lore dossier, concept sheet, claim ledger, and safety checklist

## Hard boundary

This is **not**:

- scientific validation  
- medical-device assessment  
- patent search or procurement advice  
- buildable time-travel, singularity, exotic-matter, or radioactive wearable hardware  

Temporal-displacement language is **fiction and visualization only**.

## First safe demo

Purely visual sandbox with:

- adjustable **timeline branches**
- **light-cone tilt**
- **entropy score**
- **causality-risk** meters
- fictional circlet prop chrome

It does **not** model buildable time-travel hardware, radioactive power systems, singularities, or wearable high-speed rotors.

## Run

```bash
cd ~/Desktop/CHRONOS-VII-The-Circlet
open index.html
# or
python3 -m http.server 8765
# then visit http://127.0.0.1:8765
```
