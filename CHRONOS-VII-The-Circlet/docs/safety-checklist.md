# CHRONOS-VII — Safety & Impossible-Physics Checklist

Complete this checklist before any public showcase or pitch.

## Classification

- [ ] Banner visible: **EXPERIMENTAL / CINEMATIC SIMULATION ONLY**
- [ ] No claim of scientific validation, medical assessment, or procurement
- [ ] Temporal language labeled as fiction / visualization

## Hardware & radiation (must remain absent)

- [ ] No tritium / beta-voltaic power design details for real build
- [ ] No radioactive material handling instructions
- [ ] No singularity / exotic-matter fabrication steps
- [ ] No high-RPM wearable rotor mechanical drawings for manufacture
- [ ] No “how to build a CTC” engineering procedure

## Software demo

- [ ] Only visual spacetime sandbox (branches, cones, meters)
- [ ] Risk meters explained as narrative scores
- [ ] Ghosting / erosion framed as **UI story states**, not medical symptoms
- [ ] No instructions that could be mistaken for real device operation

## Materials language

- [ ] Zerodur, YBCO, mu-metal, HfCN appear only as **lore / prop labels**
- [ ] Material cards map to UI skins, not shop BOMs for impossible systems

## Public copy

- [ ] Pitch says “cinematic simulation / educational visualization”
- [ ] Avoid “we built a time ring” phrasing
- [ ] Prefer “we built a sandbox that stages the myth of The Circlet”
