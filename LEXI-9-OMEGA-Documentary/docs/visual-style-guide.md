# Visual Style Guide

## Palette
| Token | Value | Use |
|---|---|---|
| Void black | `#050607` | Backgrounds |
| Blueprint white | `#E8E6DC` | Lines, body text |
| Ultraviolet | `#7B5CFF` | Accents, clearance UI |
| Acid / Lexi green | `#C8FF35` | Active system, success |
| Terminal amber | `#FFB020` | Warnings, work-in-progress |
| Danger orange | `#FF5C35` | Blocked claims, risk stamps |

## Motifs
- Black field + white blueprint lines  
- Ultraviolet glow accents  
- Terminal overlays (monospace, scanlines light)  
- Transparent glass UI cards  
- Slow orbiting 3D wireframes  
- Android phone close-ups  
- Mac terminal shots  
- “Official Determination” document stamps  
- Engineering callouts + cinematic labels  

## Type
- **Display / titles:** geometric sans, tight tracking  
- **UI / stamps:** mono (`IBM Plex Mono` / `SF Mono`)  
- **Narration cards:** clean sans, high contrast  

## Camera language
| Shot | Feeling |
|---|---|
| Extreme close-up on code | Mind at work |
| Overhead desk / phone | Builder life |
| Slow push into UI | System awakening |
| Split screen phone + Mac | Dual-runtime companion |
| Stamp slam (sound design) | Governance / truth boundary |
| Soft rack focus blueprint → face | Myth → maker |

## On-screen labels (examples)
- `SYSTEM NOMINAL · v0.9`  
- `CURATOR ACCESS`  
- `LEVEL IX CLEARANCE`  
- `PROOF OF USEFULNESS`  
- `SIMULATION ONLY`  
- `GOVERNANCE LAYER ACTIVE`  

## What not to show as “real finished tech”
- Spacetime folding / time travel as product  
- Rooted phone implants / SystemUI conquest  
- Exotic propulsion as delivered engineering  
- Medical claims from fictional side effects  

Stamp those frames: **CONCEPT · SIMULATION · RESEARCH DIRECTION**
