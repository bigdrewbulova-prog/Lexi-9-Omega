# Production Checklist

## Capture
- [ ] Record founder intro (2–4 min talking head + 30s punchy version)
- [ ] Capture Android / Termux screen (boot, command loop, memory save)
- [ ] Capture Mac terminal screen (launcher, blueprint generation)
- [ ] Desk B-roll: phone, laptop, notebook, coffee, hands typing
- [ ] UI B-roll: persona cards, clearance motif, blueprint PDF scroll

## Product assets
- [ ] Create **one** sample Brand Blueprint Pack (`samples/`)
- [ ] Export pack as PDF + PNG cover
- [ ] Create **3** ad graphics (see `launch/ad-copy.md`)
- [ ] Draft landing page copy
- [ ] Draft client intake form questions
- [ ] Before/after example pair

## Audio
- [ ] Film / record full VO bank
- [ ] Record cold-open narration clean
- [ ] Room tone 30s
- [ ] Optional: UI click pack / soft drone bed

## Edit path
- [ ] Assemble **2-minute trailer** first (`scripts/trailer-2min.md`)
- [ ] Internal review: claims grounded? product clear?
- [ ] Expand to **~12-minute documentary** or episodic cuts
- [ ] Color: black / white blueprint / UV accents
- [ ] Lower-thirds + stamps (PROOF / SIMULATION / GOVERNANCE)

## Launch readiness (Act VII)
- [ ] Facebook ad image
- [ ] “5 spots open” offer post
- [ ] One-page sample pack public-safe
- [ ] Short video (trailer)
- [ ] Landing page live or Canva link
- [ ] Intake form live
- [ ] Price shown: starting $50

## Truth / governance gate
- [ ] No impossible tech presented as finished
- [ ] Physics segments labeled simulation / concept
- [ ] Android path: no root, no wipe, no SystemUI implant claims
- [ ] Final line lands on usefulness
