# Google Drive / Google AI Studio Import Notes

For a safe first version, export your Google Drive Docs, Google AI Studio prompts, Firebase configs, and Cloud notes as local files, then add that folder to `config/sources.json`.

Later module:
- OAuth login
- Read-only Google Drive file listing
- Export Docs/Sheets/Slides to text
- Add to Lexi index
- Keep a local manifest of file IDs and modified times
