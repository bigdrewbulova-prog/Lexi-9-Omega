# Lexi.AI User-Space Prototype to Official App Path

## Operating Rule
Run Lexi.AI as a safe user-space prototype first. Build official app features only after the workflow is useful, repeatable, permission-safe, and testable.

## Stage 1: User-Space Prototype
The prototype runs without privileged device control, account bypassing, hidden surveillance, or OS modification.

Build now:
- Local CLI planning and project memory
- AI Brand Blueprint Pack generator
- Documentary and offer mapping
- Local file outputs in Markdown, JSON, HTML, and SQLite
- Web dashboard shell
- Android Termux helpers only through user-approved commands
- Evaluation logs for prompts, templates, and generated deliverables

Allowed boundaries:
- Read and write local project files created or selected by the user
- Use user-space Android intents, Termux:API, and explicit permissions
- Store project memory locally
- Prepare drafts, plans, and code for review

Blocked boundaries:
- Hidden account access
- Password collection
- Security bypass
- Background surveillance
- OS-level control outside official APIs
- Claims that speculative physics is finished hardware

## Stage 2: Official App Features
Promote only proven prototype workflows into platform-native features.

Build later:
- Native Android app screens for brand packs, memory, and project status
- Share sheet / file import flows
- Notification reminders
- Local SQLite library for saved packs and prompts
- Optional account sync through official OAuth only
- Permission screens for camera, files, microphone, notifications, and location
- Export actions for Markdown, PDF, ZIP, and customer packages
- Test/evaluation dashboard for generated outputs

## Promotion Gate
A prototype feature can become an official app feature only when it has:
- Clear user value
- Explicit permissions
- Stable input and output format
- Local error handling
- Test cases or manual validation notes
- Privacy and safety notes
- A rollback path

## First Product Path
Start with Custom AI Brand Blueprint Packs at $50.

Prototype:
1. Capture project type, name, vibe, audience, offer, and colors.
2. Generate bio, slogan, image prompt, ad copy, and concept sheet.
3. Save the result locally.
4. Review quality with a small checklist.

Official app:
1. Add a guided intake screen.
2. Add saved pack history.
3. Add export/share actions.
4. Add payment and customer management only after the workflow is reliable.
