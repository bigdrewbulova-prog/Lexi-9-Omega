# Skill Profile: MODEL G-2025 (XT2513-1) Mobile Hardware Interface

Created: 2026-07-07

## Source Intake
MODEL G-2025 (XT2513-1) was provided as an advanced mobile hardware interface
concept for Android 16-era mobile hardware, kernel compatibility, baseband
identity, telemetry validation, and secure communication language.

## Skill Status
Restricted-design profile.

This skill is safe only as:
- Device capability documentation
- Android companion-app planning
- User-space diagnostics
- Permission and privacy review
- Compatibility checklist generation
- Non-invasive telemetry status modeling

## Safety Boundary
Do not build, run, or provide operational instructions for:
- Secure enclave provisioning
- Baseband firmware modification
- Kernel driver tampering
- Mimic-handshake package installation
- Hardware identity spoofing
- Network handshake bypass
- Serial signature cloning
- Carrier, modem, or boot-chain modification

## Safe Conversion
The provided fabrication sequence is converted into a read-only planning skill.
Lexi can help document what a legitimate Android companion app should check
through public APIs and user-approved diagnostics.

Allowed outputs:
- Device profile summary
- Safe Android companion requirements
- Permission checklist
- Non-invasive diagnostic flow
- Kernel/baseband version inventory notes
- Risk ledger for restricted operations

## Blocked Operation Ledger
| Source claim | Safe handling |
| --- | --- |
| Provision secure enclave serial signature | Blocked; record only as unverified device-identity claim. |
| Deploy Android system image/kernel | Blocked; point to official OEM update tools only. |
| Configure baseband firmware | Blocked; modem/baseband firmware changes are out of scope. |
| Execute mimic-handshake package | Blocked; no handshake mimicry, bypass, or spoofing workflow. |
| Telemetry parity validation | Allowed only as user-space status reporting from public APIs/logs. |

## First Safe Build
Create a local `device_profile` data model that stores:
- model_name
- sku
- android_version
- kernel_version
- baseband_version
- companion_app_mode
- permission_state
- diagnostics_status
- blocked_operation_flags

## Recommended App Feature
Build an Android companion screen called `Device Status` that shows:
- User-entered or public API-reported model/SKU
- Android and kernel version
- Baseband version as read-only text
- Network status from normal Android APIs
- Permission state
- Warning banner for restricted operations

## Lexi.PHYS Verdict
This belongs in Lexi as a safe mobile-hardware profile skill, not as firmware,
baseband, or secure-enclave automation.
