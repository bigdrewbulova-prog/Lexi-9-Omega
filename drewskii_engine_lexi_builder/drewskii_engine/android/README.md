# Android Bridge

This folder is for safe Android helper actions.

Use official, permission-based tools only.

Good examples:
- `termux-tts-speak "Lexi online"`
- `termux-vibrate`
- `termux-camera-photo` after permission
- `termux-location` after permission
- Android intents that the user approves

Not allowed:
- hidden surveillance
- stealing accounts
- bypassing lock screens
- scraping private data without consent
- malware or persistence tricks
